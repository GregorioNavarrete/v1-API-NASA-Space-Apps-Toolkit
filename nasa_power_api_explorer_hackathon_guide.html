Cómo dominar la NASA POWER API en un Hackatón

El mayor error en el Space Apps Challenge es perder horas intentando comprender física atmosférica. Tu trabajo como desarrollador es abstracción de datos: pasar de ecuaciones complejas a funciones de código limpio.

1. El Paradigma de la "Caja Negra" (Black Box)

Trata a la API de la NASA como un microservicio precalculado. No intentes rehacer los algoritmos de satélites o simulaciones térmicas de la NASA. Solo define claramente tus Entradas (Inputs) y tus Salidas (Outputs).

INPUTS (Tus Parámetros)
  • • Latitud & Longitud
  • • Rango de Fechas
  • • Parámetros (T2M, RH2M)
  • • Formato (JSON)
OUTPUTS (Variables Útiles)
  • • Dicionario fecha: valor
  • • Muestras meteorológicas
  • • Métricas de confort/riesgo
  • • Tendencias climáticas
01

Navegando la Estructura de la Respuesta NASA

La NASA POWER API devuelve un objeto JSON jerárquico. Los datos numéricos clave no vienen en un array simple, sino dentro de un mapa indexado por fechas en formato YYYYMMDD bajo properties.parameter.

JSON Path:
response.properties.parameter.T2M["20240101"]
02

Estrategia de Fallback (Offline Mode)

Durante la maratón de 48h, las APIs públicas de la NASA pueden sufrir latencia o bloqueos por exceso de tráfico mundial. Implementa siempre un patrón Try/Catch que cargue un archivo JSON estático en caso de timeout.

const data = await fetch(API_URL).catch(() => MOCK_LOCAL_DATA);

// Función lista para usar en tu proyecto de React, Vue o JS Vainilla
async function getNasaWeather(lat, lon, startDate, endDate) {
  const params = new URLSearchParams({
    parameters: 'T2M,RH2M',
    community: 'RE',
    longitude: lon,
    latitude: lat,
    start: startDate.replace(/-/g, ''), // Convierte YYYY-MM-DD a YYYYMMDD
    end: endDate.replace(/-/g, ''),
    format: 'JSON'
  });

  try {
    const response = await fetch(`https://power.larc.nasa.gov/api/temporal/daily/point?${params}`);
    if (!response.ok) throw new Error(`HTTP Error: ${response.status}`);
    
    const json = await response.json();
    return json.properties.parameter; // Devuelve el objeto con las series temporales
  } catch (error) {
    console.warn("API de la NASA no disponible. Usando datos de respaldo (Mock)...", error);
    return MOCK_NASA_DATA;
  }
}

Comando cURL para Consola

Puedes probar la API directamente desde tu terminal de Linux/Mac/Windows ejecutando este comando cURL:

curl -X GET "https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,RH2M&community=RE&longitude=-64.26&latitude=-27.78&start=20240101&end=20240107&format=JSON"

Exportar Código desde Postman

Una vez validada la respuesta en Postman:

  1. Haz clic en el icono </> (Code Snippet) en el panel derecho de Postman.
  2. Selecciona tu lenguaje: JavaScript - Fetch o Python - Requests.
  3. Copia y pega el código generado directamente en tu archivo del proyecto.
